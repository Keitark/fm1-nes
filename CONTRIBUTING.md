# Contributing

Please keep this repository a source-only custom-firmware research example.

- Identify the origin and license of adapted code, tables and assets in your
  change. Retain upstream notices and describe modifications. Referencing a
  repository is not a substitute for permission to reuse its contents.
- Do not contribute stock firmware images, disassembly dumps, commercial ROMs,
  chip keys, credentials, personal device identifiers, toolchain archives or
  private session logs. Generated firmware and embedded-ROM sources stay local.
- New source paths require explicit updates to `public-files.txt` and its
  matching `.gitignore`. Do not use `git add -f` to bypass a release exclusion.
- Run the checks in PUBLICATION.md. Keep technical test results separate from
  hardware qualification or legal claims. Do not weaken a failing static audit.
- Discuss a questionable contribution by file and origin; do not post sensitive
  evidence in an issue, PR, screenshot or Actions log. If private evidence is
  needed, first agree on an appropriate private channel with the maintainer.
- Contributions are intended under this project's Apache-2.0 terms only to the
  extent you have the right to contribute them; third-party terms remain intact.
